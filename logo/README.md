# The Ageris logo

| File | Use |
|---|---|
| `ageris-logo-light.svg`, `ageris-logo-dark.svg` | The name, for light and for dark backgrounds |
| `ageris-logo-tagline-light.svg`, `ageris-logo-tagline-dark.svg` | The name with the tagline |
| `ageris-icon-light.svg`, `ageris-icon-dark.svg` | The icon alone |
| `ageris-no-fill.svg`, `ageris-icon-no-fill.svg` | One color, taken from the surrounding text (`currentColor`) |
| `favicon.svg`, `favicon-32.png`, `favicon-180.png` | Favicon |
| `ageris-social.png` | Preview image for links to the repository, 1280x640 |

The letters are black (`#0b0b0b`) on light backgrounds and near-white (`#f0f3f6`) on dark ones. The dot is green: `#1FA971` on light, `#34D399` on dark.

The letters are outlines of [Inter](https://rsms.me/inter/) by Rasmus Andersson, which is under the SIL Open Font License 1.1. The files need no font.

## Using the logo

The logo files are under the Apache License 2.0, like the rest of this repository. Use the logo to refer to Ageris, for example in an article, a talk or a list of libraries. Do not use it in a way that suggests your project or product is Ageris or is endorsed by it.
